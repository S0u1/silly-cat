捣蛋猫 · Electron 验证版（Win7 测试用）
==========================================

这是什么
--------
同一只猫，把外壳从 Tauri（依赖系统 WebView2）换成 Electron 22（自带浏览器内核，
是最后一个支持 Win7 的版本），所以：
  1. 不需要装 WebView2，也不应该再出现 "Could not find the WebView2 Runtime"；
  2. 窗口应该是真透明的（猫周围看到的是桌面/别的窗口，不是白块或米色方块）。
想请你帮忙确认这几件事在你的机器上是不是真的成立。

这只是验证版：没有设置窗口、没有自动更新、没有开机自启。


系统要求
--------
  * 64 位 Windows 7 SP1 或更新（32 位系统不支持）。
  * 最好装过 Win7 的「平台更新 KB2670838」（没装也能跑，只是可能只能软件渲染）。
  * 主题最好用 Aero（桌面右键 -> 个性化）。用「Windows 7 基本」主题的话请在回复里说一声。


怎么装（二选一）
----------------
A. 安装包  SillyCatElectronDemo_win7_x64-setup.exe
   双击 -> 一路下一步（装到当前用户，不需要管理员；可以改安装目录）-> 完成后会自动启动。
   这个安装包没有数字签名，系统或杀毒软件可能会提示"未知发布者"，请选"仍要运行/允许"。
   安装过程中如果出现任何报错，不要只是关掉窗口——见下面"出错了发什么"。

B. 免安装 zip  SillyCatElectronDemo_win7_x64.zip
   解压到一个新文件夹（路径里最好不要有特殊符号），双击 SillyCatElectronDemo.exe。
   解压出来的文件夹里还有三个启动脚本，用来对比：
     start-no-gpu.bat         关闭 GPU 加速（软件渲染）启动
     start-debug.bat          窗口外画一圈紫红+青色的细边框，用来看"透明区域到底在哪"
     start-debug-no-gpu.bat   两个一起

启动后猫出现在屏幕右下角，任务栏右下角通知区还有一个猫图标（右键或左键点它是菜单）。
只想退出：右键猫 -> 退出，或者托盘图标 -> 退出。


请观察并回复这些（有就写，没有写"没有"）
------------------------------------------
1. 透明：猫的身后和周围是不是直接透出桌面/别的窗口？有没有白色、米色、黑色的方块底？
   用 start-debug.bat 启动，截个图发过来（边框里面除了猫应该都是透明的）。
2. 对比 GPU：分别用正常启动和 start-no-gpu.bat 启动，透明效果、动画流畅度有没有区别？
3. 跟打字：在记事本里打字，猫会不会伸爪按对应的键？点鼠标、移动鼠标，猫有反应吗？
   （已知：以"管理员身份"运行的窗口里的按键，猫看不到。）
4. 点穿：猫周围的空白处点一下，是不是点到了后面的窗口/桌面图标？点在猫身上不应该穿透。
5. 拖动：按住猫的身体（不是头）拖动，窗口会跟着走吗？松开鼠标后是不是停在松手的位置？
   按住猫的头是"摸头"，不是拖动。
6. 右键猫：弹出菜单（显示/隐藏猫、锁定位置、重置位置、打开日志文件夹、退出）。
   选完一项或点别处，菜单会正常关掉吗？如果点别处菜单不消失，请记下来。
7. 安装过程：有没有出现任何跟 WebView2、VC++ 运行库、.NET 有关的报错？
8. 资源占用：任务管理器里 SillyCatElectronDemo.exe 的 CPU 大概占多少？
9. 你的环境：Windows 版本（开始菜单 -> 右键"计算机" -> 属性，看版本和 Service Pack）、
   显卡型号、是不是虚拟机或远程桌面、是不是 Aero 主题。


出错了发什么（很重要）
----------------------
请把下面两个文件发回来（用记事本能直接打开，里面只有版本号、系统信息、显卡状态、运行事件；
不会记录你按过哪些键，只记按键的总次数）：

  1. 安装日志  install.log   —— 安装器写的，装不上/中途关窗口也会留下
  2. 运行日志  demo.log      —— 猫启动后写的，启动失败/闪退/没有猫时看它

它们都在同一个文件夹：
  %APPDATA%\SillyCatElectronDemo\
  （在资源管理器地址栏里粘贴上面这行回车即可；Win7 上通常是
    C:\Users\你的用户名\AppData\Roaming\SillyCatElectronDemo\ ）
  猫已经启动的话，也可以：右键猫 -> 打开日志文件夹。

  * 安装失败时，安装器会弹窗告诉你 install.log 的位置。
  * 猫启动失败时，程序会弹出错误框并写好 demo.log，请把错误框截图 + demo.log 一起发来。
  * 就算一切正常，也请发一份 demo.log（里面有显卡和透明相关的信息，对我们判断很有用）。
  * 想让日志里多一些信息：用 start-debug.bat 启动，日志里每 10 秒会多一行键鼠事件累计数，
    用来判断全局键鼠钩子到底有没有装上。
