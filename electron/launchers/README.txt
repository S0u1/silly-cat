捣蛋猫 · Electron 验证版（64 位 Windows 7 / 8 / 10 / 11 都可以试）
================================================================

这是什么
--------
同一只猫，把外壳从 Tauri（依赖系统的 WebView2）换成 Electron 22（自带浏览器内核，不需要 WebView2）。
想请你试试：
  1. 原版装不上、或者启动时提示 "Could not find the WebView2 Runtime" / "无法下载 WebView2" 的电脑，
     装这一版能不能直接用，不再报 WebView2 的错；
  2. 在 Windows 7 上，猫周围能不能是真透明的（原版 Win7 上猫周围有一块底色）。

这只是验证版：没有设置窗口、没有自动更新、没有开机自启。


适合谁
------
  * 装原版 SillyCat 时报错的人（Win7 / Win8 / Win10 / Win11 都行）。
  * Windows 7 用户（顺便看透明效果）。
  请先退出原版 SillyCat 再试：两个同时开，猫会叠在一起，而且都会监听键盘鼠标。


系统要求
--------
  * 必须是 64 位 Windows：Windows 7 SP1、8、8.1、10、11。
  * 32 位系统装不了（安装器会提示"需要 64 位 Windows"然后退出）。怎么看是不是 64 位：
      Win7：开始菜单 -> 右键"计算机" -> 属性 -> 系统类型
      Win10/11：设置 -> 系统 -> 关于 -> 系统类型
  * 只有 Win7 才需要关心：最好装过「平台更新 KB2670838」（没装也能跑，只是可能只能软件渲染）；
    主题最好用 Aero（桌面右键 -> 个性化）。用「Windows 7 基本」主题的话请在回复里说一声。


怎么装（二选一）
----------------
A. 安装包  SillyCatElectronDemo_x64-setup.exe
   双击 -> 一路下一步（装到当前用户，不需要管理员；可以改安装目录）-> 完成后会自动启动。
   这个安装包没有数字签名，系统或杀毒软件可能会提示"未知发布者"，请选"仍要运行/允许"。
   安装过程中如果出现任何报错，不要只是关掉窗口——见下面"出错了发什么"。

B. 免安装 zip  SillyCatElectronDemo_x64.zip
   解压到一个新文件夹（路径里最好不要有特殊符号），双击 SillyCatElectronDemo.exe。
   解压出来的文件夹里还有三个启动脚本，出问题时用来对比：
     start-no-gpu.bat         关闭 GPU 加速（软件渲染）启动
     start-debug.bat          窗口外画一圈紫红+青色的细边框，用来看"透明区域到底在哪"
     start-debug-no-gpu.bat   两个一起

启动后猫出现在屏幕右下角，任务栏右下角通知区还有一个猫图标（右键或左键点它是菜单）。
只想退出：右键猫 -> 退出，或者托盘图标 -> 退出。


请观察并回复这些（有就写，没有写"没有"）
------------------------------------------
所有系统都请回答：
1. 安装：有没有出现任何跟 WebView2、VC++ 运行库、.NET 有关的报错？装好了吗？
2. 猫有没有出现在屏幕右下角？
3. 跟打字：在记事本里打字，猫会不会伸爪按对应的键？点鼠标、移动鼠标，猫有反应吗？
   （已知：以"管理员身份"运行的窗口里的按键，猫看不到。）
4. 点穿：猫周围的空白处点一下，是不是点到了后面的窗口/桌面图标？点在猫身上不应该穿透。
5. 拖动：按住猫的身体（不是头）拖动，窗口会跟着走吗？松开鼠标后是不是停在松手的位置？
   按住猫的头是"摸头"，不是拖动。
6. 右键猫：弹出菜单（显示/隐藏猫、锁定位置、重置位置、打开日志文件夹、退出）。
   选完一项或点别处，菜单会正常关掉吗？如果点别处菜单不消失，请记下来。
7. 你的环境：Windows 版本和位数、显卡型号、是不是虚拟机或远程桌面；
   以及【原版 SillyCat 当时报的是什么错】（最好截图，原样告诉我们）。

Win7 / Win8 用户另外回答：
8. 透明：猫的身后和周围是不是直接透出桌面/别的窗口？有没有白色、米色、黑色的方块底？
   用 start-debug.bat 启动，截个图发过来（边框里面除了猫应该都是透明的）。
9. 对比 GPU：分别用正常启动和 start-no-gpu.bat 启动，透明效果、动画流畅度有没有区别？

觉得卡的话：
10. 任务管理器里 SillyCatElectronDemo.exe 的 CPU 大概占多少？


出错了发什么（很重要）
----------------------
请把【桌面上】的这两个文件发回来（每次安装、每次启动都会写，不是只在出错时才写）：

  1. SillyCatDemo-install.log   —— 安装器写的。装不上、中途关窗口、装好了都会有。
  2. SillyCatDemo-run.log       —— 猫启动后写的。启动失败/闪退/没有猫时尤其要看它。

  * 用记事本直接打开就行（UTF-8，中文不会乱码）。里面只有版本号、系统信息、显卡状态、
    安装和运行过程中的事件；不会记录你按过哪些键，只记按键的总次数。
  * 日志里不写任何文件路径（所以不会带你的 Windows 用户名）：安装目录、程序目录这些，
    只记盘符、路径里有没有中文或空格、长度这类特征。
  * 就算一切正常，也请发这两个文件（里面有系统和显卡的信息，对我们判断很有用）。
  * 只用 zip 的话没有安装器，就只有 SillyCatDemo-run.log。
  * 安装失败时，安装器会弹窗告诉你日志在哪。猫启动失败时，程序会弹出错误框并写好日志，
    请把错误框截图 + 日志文件一起发来。
  * 如果桌面写不了（比如桌面被设成了只读，或者没有权限），日志会退回到这里：
      %APPDATA%\SillyCatElectronDemo\
    （在资源管理器地址栏里粘贴上面这行回车即可；通常是
      C:\Users\你的用户名\AppData\Roaming\SillyCatElectronDemo\ ）
    文件名不变。发生这种情况时，弹窗里和日志第一行都会写明。
  * 猫已经启动的话，也可以：右键猫 -> 打开日志文件夹（会在资源管理器里选中猫的运行日志）。
  * 想让日志里多一些信息：用 start-debug.bat 启动，日志里每 10 秒会多一行键鼠事件累计数，
    用来判断全局键鼠钩子到底有没有装上。
